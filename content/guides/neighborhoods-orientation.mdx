## What this page is for

A finished guide would define the area names people use, in plain language, so a newcomer knows where a name sits. This draft does not characterize any area.

## Names a finished guide might define

These are names to write entries for. No description is included on purpose.

- Downtown and the bayfront
- The Southside
- Flour Bluff
- Calallen
- North Padre Island

## What a fair entry includes

- Where the area sits relative to the bay or the gulf
- Who it tends to be convenient for, only if the editor knows that firsthand
- A note about flood, wind, or insurance only when it cites a current official source

## Leave out

- Rankings and "up and coming" claims
- Home prices and rent
- School ratings and crime claims
- Invented boundaries
